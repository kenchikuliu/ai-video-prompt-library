# GPT-Image-2 Composition Template

Use this for one storyboard frame before I2V.

```text
16:9 landscape storyboard frame for an AI-generated short video.
Scene role: [hero / demo / transformation / close-up / ending].
Main subject: [specific subject].
Composition: [foreground], [middle ground], [background], with [safe negative space] for later captions.
Camera: [wide / medium / close-up / macro], [lens feel], [angle].
Lighting: [specific direction and softness].
Palette: [3-5 concrete colors].
Motion intent for later video: [one simple motion].
Style: realistic cinematic commercial frame, clean hierarchy, high detail.
Do not include subtitles, watermarks, fake UI labels, random logos, model names, workflow words, or long readable text.
```

## Product Shot

```text
16:9 landscape product-video storyboard frame.
Use the provided product reference assets as the source of truth for shape, color, packaging, material, and silhouette.
Layout: product hero zone on [left/right/center], clean negative space on [left/right/top] for HTML/caption text, one small supporting prop zone.
Scene role: [hero reveal / use demo / scale comparison / final close].
Lighting: [soft window light / studio strip light / warm tabletop light].
Palette: [concrete colors].
Background: [studio / kitchen counter / desk / vanity / outdoor surface].
Motion intent for later video: [camera push-in / slow orbit / hand enters frame / steam rises / liquid pours].
No old product names, no fake logos, no unrelated labels, no workflow/model/tool words, no clutter, no text crossing the product.
```

## UGC Shot

```text
16:9 landscape storyboard frame for a realistic social media UGC product demo.
Main subject: [person/hands] using [product] in [real location].
Composition: natural handheld framing, product clearly visible, face/hands anatomically natural, background clean but lived-in.
Lighting: believable indoor daylight, not glossy studio.
Motion intent for later video: [one clear action].
Leave clean space for captions outside the subject and product.
No subtitles, no watermark, no extra fingers, no distorted face, no random logos, no long readable text.
```
